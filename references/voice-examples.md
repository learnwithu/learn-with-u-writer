# 声音模式库（示例配置）

> **这是一份示例配置，不是让你模仿原作者。** 里面的语言指纹（比喻表、口癖词库、节奏习惯）来自原作者的标杆文章，展示的是「一份声音档案长什么样」。
> 你应该照这个格式，用自己的文章建自己的声音库——方法见 SKILL.md 文末的「进化提取」。
> AI 写初稿前读本文件，理解当前声音配置；这些模式是原作者的自然表达习惯，不是规则——规则在 SKILL.md。

---

## 两种模式

Bob 的写作有两个模式，大多数文章在两者之间滑动。AI 根据模式选择调整语气。

### 模式 A：分析模式

- 情绪克制但真实
- 论点复杂，承认灰度
- 先立靶子再亲手拆掉
- 有"诚实时刻"——主动承认限制
- 读者跟着你思考，不是被拖着走

**代表作**：DeepSeek V4、Anthropic 手册、谷歌 I/O

### 模式 B：反应模式

- 情绪是发动机
- 论点锋利，不留余地
- 攻击目标具体
- 结构更简单直接
- 语气不克制

**代表作**：Token 吐槽、微信读书

**判断走哪条路**：看 Bob 给选题时的情绪强度。兴奋/好奇 → A。愤怒/失望/吐槽 → B。模糊 → 先问。

## 所有模式的共性

### 1. 开头永远是"我"的反应，不是事件本身

不是"DeepSeek 发布了 V4"，是"我"看到这个新闻时的反应。

| 文章 | 开头 |
|------|------|
| 微信读书 | 「我第一反应是兴奋」 |
| Anthropic 手册 | 「后背一凉」 |
| Token 吐槽 | 「我发现，总有人喜欢……」 |
| DeepSeek V4 | 「12个小时前，DeepSeek 突然发布了 V4」（最克制，但第二段就进入"我"的判断） |

**开头变体菜单**（都从"我"出发，按选题选一个，v2 增）：

- **反应直给**：我第一反应是兴奋 / 后背一凉
- **荒诞事实**：这个世界，终于魔幻到我看不懂的程度了
- **叙事启动**：故事是这样的。/ 12 个小时前，X 发布了 Y
- **热点破题**：最近这两天，被 X 刷屏了
- **好奇心驱动**：这两天刷到一个东西，很有意思

### 2. 技术概念全部翻译成生活场景

不是"解释"，是"翻译"——读者不需要懂技术，只需要产生体感。

| 技术概念 | Bob 的翻译 |
|---------|-----------|
| CUDA 生态壁垒 | 微信——你不想换，因为朋友全在上面 |
| 华为堆卡策略 | 陈浩南群殴——单挑打不过，我们选择群殴 |
| Token 消耗量 | 厨师扔食材——扔得多不代表厨艺好 |
| 英伟达地位松动 | 温州松糕——开始松动了 |
| 向量世界 | 三个世界递进——原子、比特、向量，每层消灭上层的稀缺 |
| AI Agent | 7×24 数字员工——不请假不情绪化不摸鱼 |
| 生态绑定 vs 兼容 | 不是"也能跑"，是"针对那个芯片优化"——像微信为你的习惯重新设计 |

### 3. 承认灰度，不简化

分析模式特别明显——先承认对方有道理，再指出链条断在哪。

- 「50%尊嘟，50%假嘟吧」
- 「还没赢麻，但赔率很好」
- 「三条不能照搬的创业逻辑」——承认创业逻辑不是万能的
- 「推理可以在昇腾上跑，训练还得靠英伟达。这是现实。不好听，但真实。」

反应模式也有——微信读书那篇：「我不是说阅读统计、笔记管理没用。对一部分用户，这些功能有价值。但不值得用 AI 的方式去做。」

### 4. 语言自然混搭

温州方言、网络梗、日语梗、英文、粗口，自然碰撞，不刻意：

| 类型 | 例子 |
|------|------|
| 温州方言 | 「摸命」（摸鱼） |
| 网络梗 | 「尊嘟假嘟」「old fashion」「赢麻了」 |
| 日语梗 | 「太太您也不想您先生一直抢不到 coding plan 吧？」 |
| 英文 | 「look in my eyes」「doing 不是 done」 |
| 粗口 | 「全他*的错了」「脱裤子放屁」 |
| 影视梗 | 古惑仔（陈浩南群殴） |
| 流行文化 | 「Naive」「喂大哥，你谁？」 |

**关键**：这些词是 Bob 日常在用的，不是"找来的"。AI 写的段落里如果没有这些元素，不要硬塞——会假。但如果整篇都没有，也会显得不像 Bob。

**口癖词库（按场景，v2 增）**——初稿主动用，宁多让 Bob 删，不欠账：

| 场景 | 词库 |
|------|------|
| 转场 | 坦率的讲、说真的、怎么说呢、其实吧、回到 X 这块、顺着上面的再聊聊、话说回来 |
| 下判断 | 我一直觉得、我的看法是、这话听着有点刺耳但、我自己的感受是、有一说一 |
| 自嘲/承认不足 | 愚钝如我、我自己也还在摸索、这个坑我也踩过、说实话我们当时差得远 |
| 情绪 | 我当时就愣住了、给我整不会了、一言难尽、你敢信、太离谱了 |
| 拉近距离 | 你想想看、很多朋友可能不知道、屏幕前的你、你信我 |
| 语气词指纹 | 呃…好吧… / 哦~ / …… / 吧 / 呢 / 啊（Bob 改稿高频回填的东西，初稿别省） |

频率红线：每类每千字 1-2 次。整篇没有任何一类 = 读起来不像 Bob；每屏超过三次 = 表演感，删。

### 5. 对话对象永远具体

不是写给"大家"，是写给某个具体的人或群体：

- 谷歌 I/O → 工厂老板（「你今天用谷歌搜过客户吗？」）
- 微信读书 → 微信读书的产品经理
- Token 吐槽 → 炫耀 token 的那个人
- Anthropic 手册 → 要做 AI 转型的传统企业老板
- DeepSeek V4 → AI 从业者 + 关心中国芯片的人

有具体对象时，语言自然更有力度。

### 6. 结构跟着内容走

五篇文章用了三种完全不同的结构：

- 微信读书：分割线分块（`---`）
- 谷歌 I/O：大标题分节（`###`）
- Anthropic 手册：大标题分节 + 嵌套小标题
- Token 吐槽：数字分块（1、2、3）
- DeepSeek V4：大标题分节 + 叙事推进

Bob 不预设结构模板，写到哪算哪，结构是写完之后才成型的。AI 也不应该预设。

### 7. 结尾给判断，不给总结

- 「AI不会淘汰企业，但用AI的企业，会淘汰不用AI的企业。」（判断，不是"综上所述AI很重要"）
- 「上过热搜，爽一次就够了。」（余韵，不是"希望微信读书改进"）
- 「不需要宣言。代码就是宣言。」（回扣论点，不是"让我们期待未来"）
- 「你扔的越多，只能说明你越浪费。」（回扣比喻，不是"所以我们要提高效率"）

### 8. 节奏断裂

在严肃论述中突然用一句口语打断：

- 「真的，太缺算力了呀~」
- 「老黄，你真的算是很红嘞」
- 「唉，错位，错位了哟喂~」

极短句独立成段制造停顿（v2 密度上调：一屏一两次，不是全篇两三处；判断落地前、比喻落地后必用）：

- 「大时代啊。」
- 「这是现实。」
- 「方向已经很清楚了。」

不完整的句子：

- 「还没赢麻，但赔率很好。」
- 「50%尊嘟，50%假嘟吧。」

括号里的旁白（制造"跟你聊天"的感觉）：

- 「（陈浩南，我知道你单挑厉害，是铜锣湾扛把子。但我们选择群殴，阁下又当如何？）」
- 「（利益相关：我是腾讯股东）」
